# US Superstore Sales — Data Engineering Project

## Overview
A hands-on data engineering and analytics project using US Superstore sales data. The project will explore data quality, data transformation, dimensional modeling, SQL analysis, and reporting.

## Project Goals
- Inspect and clean the source data.
- Identify data quality issues and document decisions.
- Design dimension and fact tables for analytical queries.
- Use SQL to transform data and validate the model.
- Analyze sales and customer-related patterns.
- Document the workflow and project evolution.

## Tools
- Python
- Python Libraries
- SQL
- Sheets
- tableau


## Project Structure
- `data/` — source and processed datasets
- `notebooks/` — exploration and data preparation
- `sql/` — SQL transformations, dimensions, and facts
- `reports/` — analysis outputs
- `screenshots/` — visual evidence of project results
- `docs/` — project documentation
